# Aquarium Widget

Интерактивный десктопный виджет-аквариум с рыбками, созданный на Tauri и PixiJS

## Описание

Aquarium Widget - это десктопное приложение-виджет, реализующее интерактивный аквариум с живыми рыбками. Приложение сочетает в себе расслабляющую визуализацию, элементы симуляции экосистемы и возможность работы в режиме прозрачного виджета поверх рабочего стола. Проект создан с использованием легковесного фреймворка Tauri для десктопной оболочки и библиотеки PixiJS для рендеринга 2D-графики.

### Жанр и тип
- Тип: Десктопное приложение / Виджет / Симуляция
- Назначение: Релаксация, декорация рабочего стола, pet-проект
- Платформа: Desktop (Windows, macOS, Linux)
- Стиль: Минималистичная 2D-графика с процедурной генерацией

## Технологии

**Основные технологии:**
- Tauri 2 - фреймворк для создания легковесных десктопных приложений
- Rust - бэкенд Tauri (управление окнами, глобальные шорткаты)
- PixiJS v7.3.2 - 2D WebGL рендеринг
- JavaScript (ES Modules) - фронтенд логика
- HTML5 / CSS3 - разметка и стили

**Архитектурные паттерны:**
- Модульная архитектура - разделение кода на config, state, entities, logic, main
- Object Pooling - переиспользование объектов для оптимизации
- Finite State Machine (FSM) - управление состояниями рыбок
- Event-driven - взаимодействие между Rust и JS через события
- Singleton state - централизованное хранение состояния приложения

## Реализованные фичи

**Основные механики:**

1. **Симуляция экосистемы**
   - Рыбки с индивидуальным AI на основе конечного автомата (состояния: wander, chase)
   - Стайное поведение (алгоритм boids-подобного притяжения, строго до 5 рыбок в стае)
   - Автоматическое разделение переполненных стай
   - Система голода и поиска корма
   - Реакция на испуг с физическим рывком и визуальными эффектами

2. **Интерактивность**
   - Клик по аквариуму - испуг рыбок с эффектом ударной волны
   - Правый клик - бросок корма в точку клика
   - Кнопки управления: кормление, добавление рыбок, пузырьки, очистка
   - Автокорм с настраиваемым интервалом (каждые 15 секунд)
   - Ночной режим с фильтром яркости

3. **Визуальные эффекты**
   - Процедурная генерация подводных растений с анимацией покачивания
   - Динамические световые лучи
   - Система частиц для пузырьков
   - Анимация хвостов и плавников рыбок
   - Эффекты поедания корма и испуга

4. **Система достижений и статистики**
   - Отслеживание количества рыбок, корма, съеденного корма
   - 4 типа достижений (Повелитель стаи, Щедрая душа, Королевский пир, Аквариумный магнат)
   - Сохранение прогресса в localStorage
   - Визуализация достижений в панели статистики

5. **Режим виджета (F1)**
   - Глобальный шорткат F1 для переключения режима
   - Прозрачность окна для кликов мыши (click-through)
   - Скрытие UI-элементов в режиме виджета
   - Переключение alwaysOnTop при смене режима
   - Интеграция с Rust через Tauri Global Shortcut plugin

6. **Пользовательский интерфейс**
   - Выезжающие панели настроек и статистики
   - Адаптивная верстка
   - Плавные CSS-анимации
   - Система уведомлений
   - Тематическое оформление в морском стиле

**Технические особенности:**
- Модульная структура кода (ES Modules import/export)
- Централизованное состояние через объект state
- Конфигурация через отдельный модуль config.js
- Оптимизация рендеринга через слои (layers) в PixiJS
- Интеграция Rust backend с JS frontend через события Tauri
- Прозрачный фон окна через Tauri window configuration
- Динамическое управление свойствами окна (set_ignore_cursor_events, set_always_on_top)

## Запуск проекта

**Требования:**
- Node.js 18+
- Rust (последняя стабильная версия)
- Tauri CLI

**Установка и запуск:**

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run tauri dev

# Сборка релизной версии
npm run tauri build
```

**Готовый executable:**

После сборки находится в `src-tauri/target/release/`

## Управление

- **Левый клик по аквариуму** - испугать рыбок (рывок)
- **Правый клик по аквариуму** - бросить корм
- **F1** - переключение режима виджета (прозрачность + click-through)
- **Кнопка "Настройки"** - панель с элементами управления
- **Кнопка "Статистика"** - просмотр достижений и счётчиков

## Особенности реализации

### Режим виджета

При нажатии F1 окно становится прозрачным для курсора мыши, что позволяет кликать сквозь него по элементам рабочего стола. Это реализовано через комбинацию:
- `window.set_ignore_cursor_events(true)` в Rust
- CSS-класс `widget-mode`, скрывающий UI
- Глобальный шорткат через `tauri-plugin-global-shortcut`

### Оптимизация

- Использование слоёв в PixiJS для группировки объектов
- Пул объектов для пузырьков
- Ограничение количества рыбок (25) и корма (50) для стабильной производительности
- Разделение логики на модули для удобства поддержки
